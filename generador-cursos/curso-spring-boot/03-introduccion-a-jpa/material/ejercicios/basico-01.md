# 🟢 Básico 01 — Características y funcionalidades de JPA

## 🧩 Problema

Un compañero de equipo está armando una presentación interna sobre JPA y te
pide que revisés su lista de afirmaciones antes de publicarla, porque no está
seguro de cuáles son correctas.

## 💻 Código o contexto de partida

```text
Afirmaciones a revisar:

1. JPA permite trabajar con objetos Java sin escribir SQL directamente.
2. JPA obliga a usar siempre Hibernate como implementación.
3. JPQL es un lenguaje de consulta que opera sobre tablas y columnas, igual que SQL.
4. Las anotaciones de JPA eliminan la necesidad de archivos de configuración externos para el mapeo.
5. La API de persistencia de JPA permite operaciones CRUD sobre entidades.
6. Cambiar de Hibernate a otra implementación de JPA obliga a reescribir el código de la aplicación.
```

Para cada afirmación, indicá si es **correcta** o **incorrecta**, y justificá
brevemente las incorrectas.

## 📏 Criterios de evaluación de la solución

- Identifica correctamente las tres afirmaciones verdaderas (1, 4, 5).
- Identifica correctamente las tres afirmaciones falsas (2, 3, 6) y explica
  por qué son falsas, citando la característica o funcionalidad de JPA que
  contradicen.

## 🚧 Restricciones

Ninguna.

## 📊 Dificultad

Básico

## 🎓 Resultados de aprendizaje

RA-1, RA-2
