# 🏆 Proyectos integradores

Proyectos que integran los temas de varios módulos. Cada proyecto tiene su propia carpeta:

| Carpeta | Contenido |
|---|---|
| `enunciado.md` | Problema, análisis esperado, requisitos funcionales y no funcionales, reglas de negocio, escenarios de aceptación |
| `rubrica.md` | Criterios de evaluación con indicadores, puntajes y niveles de desempeño |
| `solucion/` | Solución paso a paso, pensada para que el estudiante la transcriba y entienda cada decisión |
