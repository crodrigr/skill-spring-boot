# 🟢 Básico 01 — Identificar la característica de Swagger que resuelve un problema

## 🧩 Problema

Para cada uno de los siguientes escenarios, identificá cuál de las seis
características de Swagger lo resuelve, y justificá tu elección en una
oración.

## 💻 Código o contexto de partida

1. Un equipo externo necesita generar, en Python, un cliente que consuma
   tu API, sin escribirlo a mano línea por línea.
2. Un desarrollador quiere explorar y probar los endpoints de una API
   directamente desde el navegador, sin instalar ninguna herramienta
   aparte.
3. Un equipo quiere asegurarse de que las solicitudes que llegan a su API
   cumplen exactamente la forma de datos esperada, rechazando las que no.
4. Un equipo quiere que la documentación de su API se actualice sola cada
   vez que cambia el código, sin mantener un documento aparte a mano.

## 📏 Criterios de evaluación de la solución

- Escenario 1: Generación de código (genera clientes en distintos
  lenguajes a partir de la especificación).
- Escenario 2: Interfaz gráfica interactiva (Swagger UI).
- Escenario 3: Validación de entradas y salidas.
- Escenario 4: Generación automática de documentación.
- Cada justificación menciona por qué las otras características no
  encajan tan directamente con el escenario.
